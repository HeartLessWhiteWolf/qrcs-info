QRCS 二维码识别

在 Microsoft Edge 中，右键图片或框选网页截图读取二维码。识别结果优先显示在网页内的小浮层中，可复制、取消或主动打开有效的 HTTP / HTTPS 链接。

图像与二维码在本机处理，解码器随扩展打包。读取原图会访问原站，点击跳转后才访问目标网站。

打开示例二维码体验页 · 阅读隐私政策

使用方式

  1. 图片上右键，选择“QR码识别”。
  2. 或点击 QRCS 工具栏图标，拖动框住二维码后松开。
  3. 核对内容后选择跳转、复制或取消，按 Esc 可以退出。

适用版本 1.0.3，需要桌面 Microsoft Edge 的 Chromium 127 或更新内核。受限页面可能改用工具栏弹层；无法自动展开时，点击图标的 QR 标记。
